# /gistify — تحويل أي مشروع إلى GitHub Gists نظيفة ومفهرسة

عند استدعاء هذا الأمر، قم بتحليل المشروع الحالي وتنفيذ الخطوات التالية بالترتيب:
1. **تفكيك المشروع إلى وحدات وظيفية مستقلة (Atomic Gists)** وتصنيفها في قوائم مهام كبرى (`collections/`).
2. **تطهير كافة الأكواد من التوكنات والبيانات الشخصية** عبر `src/secret_sanitizer.py` واستبدالها بـ `[YOUR_GITHUB_TOKEN]` و `[YOUR_GITHUB_USERNAME]`.
3. **توليد عنوان بحثي واضح وبسيط (SEO Description)** لكل Gist يسهّل العثور عليه في بحث GitHub.
4. **توليد شرح تفصيلي باللغة العربية (`GUIDE_AR.md`)** لكل Gist يوضح وظيفته وطريقة استخدامه.
5. **تحديث قوائم الـ Gists المجمعة (`collections/00_MASTER_GIST_CATALOG.md`)** ورفعها إلى المستودع أو إلى `gist.github.com`.
