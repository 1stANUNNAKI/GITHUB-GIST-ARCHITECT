# 🧠 الدروس المستفادة وتقارير التحديثات (LESSONS.md)

1. **تنظيم الـ Gists في قوائم مهام (Curated Lists):** لأن GitHub Gist لا يوفر مجلدات أصلية، فإن أفضل معمارية هي إنشاء **Gist فهرس رئيسي (`00_COLLECTION_INDEX.md`)** لكل مهمة كبرى يربط كافة الـ Gists الفرعية في جدول واحد واضح.
2. **العناوين البحثية (SEO Descriptions):** صياغة عنوان الـ Gist بالكلمات المفتاحية الدقيقة التي يبحث عنها المطورون (اللغة + الوظيفة + البروتوكول) يضاعف فرص ظهوره في نتائج بحث GitHub.
3. **التطهير المسبق الإلزامي (`Pre-Publish Sanitization`):** تمرير كل كود عبر فاحص تعبيرات نمطية صارم قبل النشر يضمن عدم تسرب أي توكن أو بريد شخصي إلى الـ Gists العامة.
